# Sensor page identity and map layout

The Sensor page overview now uses a responsive two-column arrangement. The sensor identity and description card occupies the first column, while the interactive GNSS map occupies the second column. Both cards share the same minimum height so their borders and content align visually.

At content widths below 960 pixels, the layout changes to one column. The sensor identity card remains first and the map follows it, preserving the action buttons and map controls without horizontal clipping. Operational metric cards remain in a full-width section below the identity/map row.
