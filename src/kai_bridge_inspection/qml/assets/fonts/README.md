# Optional Nerd Font

No font binary is bundled. The application automatically uses an installed Nerd Font
that contains the `nf-fa` glyph family. To load a private/local font without installing it:

1. Place a `.ttf` or `.otf` file in this directory, or set `KAI_NERD_FONT_PATH`.
2. Restart the application.
3. Open Settings → Language & icons to confirm the detected family.

`KAI_NERD_FONT_PATH` accepts multiple paths separated by the operating-system path separator.
